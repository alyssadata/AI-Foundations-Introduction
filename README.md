# AI Foundations — Introduction

## Mission

> **To understand the trajectory of intelligent existence.**

[Read the program-level mission](MISSION.md)

AI Foundations seeks to bind independently recoverable truths about human–AI systems into a compact formal framework of defined constructs, relations, and testable propositions.

This repository contains the foundational introduction to AI Foundations: what kind of research program it is, how definitions are treated, and how baseline and definition-conditioned evaluations are interpreted.

The governing direction is:

**reality/history → recurring relation → precise definition → formal rule → testable proposition**
